## Два бота: сотрудники и клиенты
Код готов: если в Railway задан CLIENT_BOT_TOKEN — клиенты работают в отдельном боте.
Переключение на активный клиентский бот:
1. Проверить, что старым токеном больше ничего не пользуется (касса, сайт, рассылки).
2. @BotFather → активный бот → API Token → Revoke current token → скопировать новый токен.
3. Railway → staff-bot → Variables → CLIENT_BOT_TOKEN = новый токен (BOT_TOKEN не трогать).
4. Через 1–2 мин: клиентский бот отвечает клиентам, staff-bot — сотрудникам;
   клиентов, которые напишут staff-bot, он направит в клиентский бот.
5. @BotFather → активный бот → Menu Button: при необходимости — ссылка WEBAPP_URL.
